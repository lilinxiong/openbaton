# Getting started

Run from the repository root:

~~~bash
bun samples/getting-started/walkthrough.mjs
~~~

The script creates a temporary HOME, discovers `manifest-example`, configures `sample-model`, matches implementation work, emits a brief handoff, records a fake completed native handle, and checks status. No ticket lifecycle, managed dispatch, real worker, or paid model is involved. Expected final line: `getting-started native-only walkthrough ok`.
