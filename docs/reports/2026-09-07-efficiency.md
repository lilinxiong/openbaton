# Baton 效果测量结果 — 2026-09-07

本次改动已降低 handoff 准备阶段的重复查询和文本体积。四份任务的串行准备改为一次批量准备后，目录查询由 4 次降至 1 次，耗时中位数由 344.54 ms 降至 67.10 ms，减少约 277 ms。**这不是整次模型任务加速或 token 节省率。真实总 token 数据未获宿主提供，仍为未知。**

## 交付范围

- 手动触发即默认派工；小任务单 worker，共享上下文的任务合并，独立任务按原生容量并行。
- brief 总量预算默认 12000 个 Unicode 码点；仅超预算返回诊断，不截断、不以字符推算 token。
- 简短结果契约和增量交接指引，保留验证证据与阻塞，详细日志通过文件引用。
- `spawn --briefs FILE` 一次准备 1–128 份使用相同选模参数的 handoff；一次选模、一次目录查询；仍由宿主启动 worker。
- 命令内复用单次扫描的 adapter registry，`spawn --json` 使用紧凑 JSON。
- 独立的离线测量脚本与真实任务观测格式；模型池和 effort 选择机制保持原语义。
